# Google Homepage Dashboard
### Interface note: 
Date and time are localized using the browser's language settings. Menu labels, tooltips, and control text remain in English in this release. Translations in progress. Locales to date: de-DE, en-US, es-ES, fr-FR.
## Tampermonkey UserScript:
(1) Analog resizable svg clock, controlContainer, and dateTimeContainer are all draggable.  
(2) Option to change wallpaper (0 - 52), manually or auto change hourly, daily, weekly, monthly.  
(3) Option to toggle wallpaper host site between GitHub, ImgBB, or Postimages.  
(4) Option to display custom logos (0 - 17), default Google logo, or leave blank.  
(5) Option for SVG Analog Clock face for light or dark theme.  
(6) Option for second hand movement for ticking or smooth sweeping.  
(7) Logo images are hard coded into script. Go into Settings, scroll down to Editor and uncheck Word wrap, then Save.
